# space-3d
Quickly generate procedural 3D space scenes in your browser with WebGL

## Summary

A fork of [wwwtyro/space-3d](https://github.com/wwwtyro/space-3d). It generates procedural 3D space skyboxes, with stars, nebulae and suns, in the browser using WebGL.

## What's inside

- `src/`: the generator source.
- `static/`: the built page assets.
- `index.html`: the app page.
- `package.json`: the build scripts.

## How to run it

Run `npm install`, then `npm start` for a live dev server, or `npm run build` to bundle `static/js/bundle.js`. A hosted version is at http://wwwtyro.github.io/space-3d.
